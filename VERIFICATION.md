# Проверка Movieboxd

Дата: 16 октября 2026. Node.js 24.21.0, npm 11.19.0.

## Подготовка бесплатной беты для Render

- Добавлены `render.yaml`, `.node-version` и `DEPLOY_RENDER.md`: один бесплатный Node Web Service, интерфейс и API на одном порту, секрет TMDB вводится в Render, SQLite-кеш в `/tmp`.
- `npm ci --include=dev` выполнен с `NODE_ENV=production` в чистой временной копии без `.env` и локальных зависимостей. Для npm использован отдельный доступный кеш в `/tmp`, поскольку запись в системный кеш ограничена окружением.
- Обновлён `@fastify/static` до 10.1.6; после установки `npm audit` сообщает 0 известных уязвимостей.
- Обнаружен и исправлен порядок регистрации маршрутов: ранее они создавались до подключения хука rate-limit. Теперь 121-й API-запрос получает 429, а `/api/health` остаётся доступным. На Render включено доверие к внутренним прокси; тест проверяет раздельные клиентские лимиты и игнорирование подставленного левого адреса.
- `npm test`: **43/43**, `npm run check` (в составе build) и `npm run build` успешны в чистой копии.
- `npm run test:production`: успешен после предоставления сетевого разрешения для локального порта. Проверены реальный запуск сервера с `HOST=0.0.0.0`, временный SQLite, health, HTML и JS, переходы на фильм / актёра, API 404/503 и отсутствие доступа к серверным файлам. Тест работает без реального ключа и не подтверждает доступность TMDB.
- Публикация на Render ещё не выполнена. Публичный HTTPS-адрес, TMDB, цепочку прокси и источники просмотра с IP Render нужно проверить после размещения. Браузерные E2E в этом этапе не запускались; прежнее ограничение описано ниже.


## Обновление панели: только прямые ссылки

Блок TMDB / JustWatch и его настройки удалены из интерфейса. Панель больше не делает запросов к `/api/watch/*`. Проверка TypeScript и production-сборка прошли после удаления; встроенный браузер подтвердил три прямые ссылки и отсутствие региональных фильтров. Закрытие Escape и возврат фокуса сохранены. Снимок: `verification/direct-only-panel.png`.

Браузерные сценарии обновлены под оставшуюся панель. Прежние проверки удалённых региональных элементов исключены. Описанная ниже ошибка запуска Playwright относится к предыдущему прогону; повторно он не запускался.

## Проверка трёх источников перед упрощением панели

Подключены Kinogo (kinogo2026.com), iFilm (ifilm.space) и «Нечего смотреть» (nechego.pw). API `/api/direct-links/:type/:id` получает название и год из настоящего TMDB, ищет в каталогах сайтов и проверяет найденные страницы. Адреса не подставляются по заранее записанному списку фильмов.

Результаты настоящей проверки без подмены ответов:

| Название | Kinogo | iFilm | Нечего смотреть |
|---|---|---|---|
| Начало (2010) | https://kinogo2026.com/23767--nachalo.html | https://ifilm.space/inception/ | https://nechego.pw/inception |
| Интерстеллар (2014) | https://kinogo2026.com/17487--interstellar.html | https://ifilm.space/interstellar/ | https://nechego.pw/interstellar |
| Солнце моё (2022) | https://kinogo2026.com/55717-solnce-moe.html | https://ifilm.space/aftersun/ | https://nechego.pw/aftersun |
| Игра престолов (2011) | https://kinogo2026.com/9972--igra-prestolov-hbo-serial.html | Точное совпадение не найдено | Точное совпадение не найдено |

Сравниваются название, год, тип проекта и canonical URL. Для iFilm дополнительно проверяется блок плеера; для «Нечего смотреть» — конфигурация плеера в ответе поиска и метаданные страницы. Наличие этих данных не гарантирует воспроизведение или доступность в регионе.

## Автоматические проверки

- `npm run check` — успешно.
- `npm test` — **41 прошёл, 0 ошибок**. Новые тесты проверяют оба адаптера, несовпадение названия/года/типа, отсутствие плеера, подмену адреса, ошибки источников, повторный запрос, ограничение размера данных и общий кеш индекса.
- `npm run build` — успешно.
- `npm run test:direct-live` — успешно: три фильма на трёх источниках и сериал на Kinogo; настоящий TMDB и настоящие ответы сайтов.
- `npm run test:e2e -- --max-failures=1` — запуск Chrome завершился SIGABRT / EPERM до проверки приложения. Из 36 тестов 1 ошибка запуска, 1 прерван, 34 не запускались. Этот прогон не считается успешным.

## Проверка встроенным браузером

На странице «Солнце моё» в Movieboxd отображаются три источника с прямыми ссылками. Кнопки iFilm и «Нечего смотреть» открыты из панели: каждая привела на страницу этого фильма на соответствующем домене в новой вкладке. На обеих внешних страницах загрузился интерфейс плеера. Воспроизведение полного фильма не проверялось.

Ссылки имеют `target="_blank"` и `rel="noopener noreferrer"`. Google-ссылок нет. В широком окне панель показывает три колонки. При проверке более узкого окна фактическая ширина браузера была 805 px: две колонки, горизонтального переполнения диалога нет. Проверку ширины 390 px не заявляем: запрошенный размер не был применён браузером.

Снимок: `verification/additional-sources-desktop.png`.

## Запуск и ограничения

- Frontend: http://127.0.0.1:5173/ — HTTP 200 после перезапуска.
- Backend: http://127.0.0.1:3001/api/health — `{ "ok": true, "tmdbConfigured": true }`.
- Приложение оставлено работающим через `npm run dev`.
- Новых ключей или ручных команд не требуется; `.env` не изменялся.
- Запросы ограничены разрешёнными доменами. Cookies и секрет TMDB не передаются источникам; сторонние скрипты сервером не исполняются.
- HTML / обычный JSON ограничены 1,5 МБ, индекс iFilm — 12 МБ. Тайм-аут источника — 25 секунд. Индекс кешируется на час, результаты фильма — до 10 минут. Ошибки не кешируются.
- HDRezka остаётся отключённым и скрытым в панели. Непроверенные зеркала не добавлены.
- Покрытие каталогов и адреса внешних сайтов могут меняться. Отсутствие совпадения и недоступность источника отображаются по-разному.
