# movieboxd — поиск просмотра и профили актёров

Рабочее приложение для поиска фильмов и сериалов: React 19, TypeScript, Vite, Tailwind CSS, React Router, Lucide, Node.js 24, Fastify и SQLite. Интерфейс на русском языке.

## Запуск

Требуется Node.js **24 или новее** (сервер использует встроенные TypeScript и SQLite).

```sh
cd /Users/sacenovaldiyar/Documents/Codex/2026-10-13/cin-va-netflix-tmdb-api/outputs/movieboxd
npm ci
test -f .env || cp .env.example .env
```

В `.env` заполните **TMDB_READ_ACCESS_TOKEN** — API Read Access Token из [настроек аккаунта TMDB](https://www.themoviedb.org/settings/api). Альтернатива — `TMDB_API_KEY`, ключ API v3. Это не пароль от TMDB. Токен никогда не отправляется во фронтенд; не используйте переменную с префиксом `VITE_`.

```sh
npm run dev
```

Откройте **http://127.0.0.1:5173**. Vite обслуживает интерфейс, Fastify работает на `127.0.0.1:3001`. Фронтенд обращается к API через прокси `/api`. После изменения `.env` или серверного кода перезапустите `npm run dev`. По умолчанию приложение доступно только с вашего компьютера.

Без ключа сервер запускается и возвращает понятную ошибку настройки. Приложение не подставляет демонстрационные фильмы вместо настоящего каталога.

## Production-сборка

```sh
npm run build
npm start
```

Откройте **http://127.0.0.1:3001**. Fastify обслуживает собранный интерфейс, API и прямые ссылки React Router. Размещение требует среды Node.js 24. SQLite используется только для восстанавливаемого кеша: постоянный диск необязателен. Статического хостинга недостаточно: сервер хранит ключ и выполняет запросы TMDB.

Для Render подготовлен `render.yaml` с бесплатным Node Web Service. Пошаговая инструкция без обязательной работы в терминале: [DEPLOY_RENDER.md](DEPLOY_RENDER.md). Проверка собранной версии: `npm run test:production` после `npm run build`.

## Что реализовано

- Главная с крупной обложкой, переключением главного фильма и горизонтальными подборками.
- Тренды дня, популярные фильмы, высокий рейтинг, фильмы в прокате, сериалы и аниме.
- Поиск по настоящему TMDB API с задержкой 350 мс, отменой устаревших запросов, фильтром типа и страницами результатов.
- Карточки: постер, название, год, рейтинг, переход к описанию и сохранение в коллекцию.
- Страница фильма или сериала: оригинальное название, описание, жанры, длительность / число сезонов, актёры, режиссёр, рекомендации.
- «Где смотреть»: автоматический поиск прямых страниц на **Kinogo, iFilm и «Нечего смотреть»**. Сервер сверяет название, год, тип проекта, canonical URL и наличие данных плеера. Региональный блок TMDB / JustWatch удалён из интерфейса. HDRezka отключён.
- Кликабельный актёрский состав, фотографии и профили `/person/:id`: биография, фильмы и сериалы, фильтры участия и типа, сортировка, поиск по проектам. Если русской биографии нет, показывается английская с пометкой.
- Кнопка трейлера появляется только для YouTube Trailer, возвращённого TMDB.
- Коллекция и недавние просмотры сохраняются в localStorage на этом устройстве.
- Состояния загрузки, отсутствующего ключа, неверного ключа, ошибки сети, ограничения частоты запросов, пустого поиска, отсутствующего постера и неизвестной страницы.
- SQLite-кеш на 10 минут, максимум 1000 записей; серверное ограничение частоты запросов и таймаут TMDB.
- Адаптивная вёрстка, подписи интерактивных элементов, управление с клавиатуры, reduced motion, атрибуция TMDB.

Название **movieboxd** взято из последнего запроса; исходное ТЗ использует CINÉVA.

## Проверка

```sh
npm run check
npm test
npm run build
npm run test:e2e
# После заполнения .env:
npm run test:live
```

`npm test`: 43 серверных и модульных теста. Дополнительно проверяются прямые ссылки, совпадение фильма, различение сериалов и ремейков, ошибки источника, кеш, ограничение HTML, запрет сторонних перенаправлений, лимит запросов и доступность health при превышении лимита. Ответы внешнего API в этих тестах контролируемые.

`npm run test:e2e`: 36 сценариев Playwright (18 × desktop / mobile); требуется Google Chrome. Сценарии используют контролируемые ответы и не подтверждают живой API. Текущий запуск ограничен ошибкой запуска Chrome в окружении — подробности в VERIFICATION.md.

`npm run test:live`: отдельная проверка настоящих главной, поиска, фильма, профиля с фильмографией и доступности фильма / сериала. Секреты не печатаются, демонстрационные данные не используются.

Для ручной проверки интерфейса на контролируемых данных:

```sh
npm run build
node tests/fixture-server.ts
```

Тестовый сервер доступен на **http://127.0.0.1:4174**. Он использует production-сборку и настоящие API-маршруты, но подменяет внешний TMDB. Фильмы, идентификаторы и оценки в `tests/fixtures.ts` — тестовые примеры, не актуальный каталог. Этот сервер не используется командами `dev` и `start`. Запрос `ошибка` имитирует сбой API, `ничегонет` — пустую выдачу.

Результаты текущей проверки и ограничения: [VERIFICATION.md](VERIFICATION.md).

## Структура

```text
src/App.tsx          Страницы, навигация, поиск и карточки
src/styles.css       Адаптивный интерфейс
src/api.ts           Загрузка данных и отмена запросов
src/library.tsx      Коллекция и недавние просмотры
src/types.ts         Типы и общие функции
server/app.ts        Проверяемые API-маршруты Fastify
server/tmdb.ts       TMDB-клиент и SQLite-кеш
server/people.ts     Профили и объединённая фильмография
server/watch.ts      Региональная доступность
src/PersonPage.tsx   Интерфейс профиля и фильтры проектов
src/WatchPanel.tsx   Панель прямых ссылок на сайты просмотра
shared/direct-links.ts  Разрешённые источники и проверка ссылок
server/direct-links.ts  Поиск на Kinogo, iFilm и «Нечего смотреть»
src/DirectLinks.tsx   Прямые ссылки и состояния источников
server/index.ts      Запуск сервера и переменные окружения
tests/               Серверные и браузерные тесты
public/              Значок приложения и официальный логотип TMDB
```

API: `GET /api/health`, `/api/home`, `/api/search?query=...&type=all&page=1`, `/api/catalog/:collection`, `/api/title/:type/:id`. Метаданные поддерживают `language=ru-RU` (по умолчанию) или `en-US`. Переключатель языка интерфейса относится к следующему этапу.

Дополнительные API: `GET /api/watch/regions`, `/api/watch/:type/:id?region=KZ`, `/api/person/:id`. Все запросы TMDB проходят через сервер и общий кеш. Профиль использует `combined_credits`, объединяет роли в одном проекте и различает фильмы / сериалы с одинаковыми ID.

## Ограничения данных о просмотре

Панель «Где смотреть» содержит только прямые ссылки на **Kinogo (kinogo2026.com), iFilm (ifilm.space) и «Нечего смотреть» (nechego.pw)**. Региональный блок TMDB / JustWatch, выбор страны, предпочтения озвучки/субтитров и фильтры стоимости удалены из интерфейса. Панель не запрашивает `/api/watch/*`. TMDB продолжает предоставлять каталог, метаданные и актёрские профили.

Проверка прямых ссылок подтверждает название, год, тип, canonical URL и данные плеера, но не воспроизведение и региональную доступность. HDRezka отключён и скрыт в панели: доступный источник подтвердить не удалось.

`GET /api/direct-links/:type/:id` принимает только тип и ID TMDB. Названия и год берутся сервером из TMDB. Поиск идёт параллельно на трёх источниках. iFilm использует свой публичный `/index.json`, «Нечего смотреть» — публичный `POST https://api.nechego.pw/search/items` с названием фильма. Затем сервер загружает найденную страницу и повторно проверяет метаданные. Адрес или slug берётся из каталога источника; ручного списка фильмов нет.

Разрешены только настроенные домены и конкретный адрес API поиска; переходы на другие домены запрещены. Скрипты источников не исполняются, cookies и секрет TMDB не отправляются. HTML и обычный JSON ограничены 1,5 МБ, общий индекс iFilm — 12 МБ и 30 000 записей. Индекс хранится в памяти час в сокращённом виде, его одновременные загрузки объединяются. Время проверки источника — 25 секунд. Результаты для фильма кешируются до 10 минут (максимум 200 записей); ошибки не кешируются. Сбой одного источника не скрывает результаты остальных.

`npm run test:direct-live` проверяет настоящий TMDB и три источника на «Начале», «Интерстелларе» и «Солнце моё», а также существующую ссылку Kinogo на «Игру престолов». Ответы не подменяются. У новых источников для этого сериала сейчас нет точного совпадения с первым годом выхода; они не выдают страницу второго сезона за весь сериал. HDRezka остаётся отключённым (`needs_source`).

Интеграция использует официальные [профили TMDB](https://developer.themoviedb.org/reference/person-details), [combined credits](https://developer.themoviedb.org/reference/person-combined-credits), [watch providers](https://developer.themoviedb.org/reference/movie-watch-providers) и правила [атрибуции](https://developer.themoviedb.org/docs/faq).
